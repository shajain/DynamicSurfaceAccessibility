# Work log: 2026-10-06 to 2026-10-08 — structure viewer

Interactive 3D viewer for inspecting lysines, their contacts and their accessibility in PDB biological assemblies and
AlphaFold models. Everything is in `src/dsa/structure_viewer/` (no other file was changed for it). This note
describes the final state only.

## Use
```python
from dsa.structure_viewer.viewer import StructureViewer
v = StructureViewer.from_pdb("4ah6")                  # biological assembly, with the AlphaFold panel
v = StructureViewer.from_pdb("8cn1", chains=["A1", "B1"])   # part of a large assembly
v = StructureViewer.from_alphafold("Q6PI48")          # AlphaFold model alone
v.show()                     # in a notebook (iframe; 720 px high with the AlphaFold panel, else 650)
v.save("_pages/4ah6.html")   # standalone page; _pages/ is gitignored
v.residues, v.bonds          # the values behind the page, as tables
```
Options: `color_by="chain"` (default) or `"protein"`; `alphafold_panel=False`. Demo and examples (4ah6 homodimer,
3r45 heteromer, AlphaFold Q6PI48, 2vnf modified lysine, part of 8cn1): `structure_viewer_demo.ipynb`.

## Files
| File | Role |
|---|---|
| `residue_data.py` | `StructureData`: drawn model, one row per residue, residue pairs in contact (`load_pdb`, `load_alphafold`) |
| `alphafold_panel.py` | AlphaFold models of the structure's UniProt ids and their superposition on each chain copy |
| `viewer.py` | `StructureViewer`: colours, page data, HTML; patches 3Dmol.js lighting |
| `viewer_template.html` | the page (3Dmol.js): panels, controls, hover / pin, van der Waals and probe view |
| `vendor/` | 3Dmol.js 2.4.2 (BSD-3-Clause), inlined into every page |
| `structure_viewer_demo.ipynb` | examples (saved with outputs cleared; each viewer adds 1–2 MB) |

## Data shown
- **Model:** PDB biological assembly (bio chains `A1`, `B1`, `A2`, …; the model the contacts and multimer SASA are
  computed on), or the AlphaFold model (chain `A`, numbered by UniProt). Waters, hydrogens and alternate
  conformations removed. Atoms are written with serial = position + 1 and mapped back to residues in the page
  (checked against residue names).
- **Per residue (hover panel):** bio chain, author chain, UniProt id, UniProt residue, residue as single letter and
  three-letter code (`K-LYS`, `K-M3L`), structure number, kind (protein / nucleic / ligand), pLDDT (AlphaFold).
- **SASA** (ASA Å², relative ASA, NZ Å² for lysines):
  - *Assembly*: `SASAMultimerStore`;
  - *Chain alone*: computed when the viewer is built, with the multimer SASA pipeline on each author chain alone
    (copies of a chain are identical alone);
  - *AlphaFold monomer*: `SASAMonomerStore`, at the same UniProt number, only if the residue type matches.
- **Lysines:** one-letter code K (LYS and modified lysines such as MLY, M3L, ALY, KCX), or a name in
  `ALL_LYSINE_NAMES` (LYZ and ALZ have no one-letter code in gemmi).
- **Residue pairs in contact:** the saved lysine contacts (a lysine NZ within 6.5 Å of a polymer residue), grouped
  per residue pair: bond types (salt bridge, hydrogen bond, cation–π, covalent isopeptide), `contact_4.5` if the
  closest atoms are ≤ 4.5 Å, `contact_6.5` always; closest atom pair and distance. Each pair has a source:
  - *Inter-chain (PDB)* / *Intra-chain (PDB)*: contacts of the drawn assembly, between / within bio chains;
  - *Intra-chain (AlphaFold)*: contacts of the AlphaFold model. On a PDB structure they are also placed on every chain
    copy of the protein by UniProt number (only where both residues have the same one-letter code); the distance is
    then the AlphaFold distance.

## Display
- **Cartoon:** *Thin* (default; helices / strands 0.3 Å thick with 3Dmol's default widths, loops as 0.22 Å round
  tubes), *Normal* (3Dmol default), *Trace* (Cα tube). Loops are styled by the secondary structure 3Dmol assigns on
  load (counts logged to the browser console).
- **Colours:** palette colour per bio chain (or per UniProt with `color_by="protein"`); chains in a light shade
  (45% towards white), lysines as sticks in a darker shade of the same colour (30% towards black).
- **Lighting:** 3Dmol's shaders light only by `max(dot(normal, light), 0)` from one camera-attached light, which
  leaves surfaces turned away from the light black and makes dark patches move while rotating. `viewer.py`
  (`three_dmol_source`) adds an ambient term to all six lighting expressions when the page is built:
  `0.4 + 0.6 × max(…)` (`AMBIENT_LIGHT = 0.4`). The vendored file is unchanged; the patch fails loudly if a different
  3Dmol version does not match.
- **Offline:** 3Dmol.js is inlined, so pages need no internet access (the editor window here cannot reach public CDNs).

## Controls (side panel)
- **Lysines:** highlights the lysines that pass every filter below (dark sticks and a translucent 2 Å halo around the
  side-chain tip, CD/CE/NZ; halos skipped above 600 lysines). The rest of the structure keeps its chain colours, 35%
  lighter. Bonded partners are not drawn until a lysine is hovered or pinned.
- **Filters, combined with AND** (within a group: OR; an unchecked group: no filter):
  - *Chains*, grouped by UniProt (the UniProt box switches all its chains; partial tick when only some are on);
  - *Bond types*: salt bridge, hydrogen bond, cation–π, covalent isopeptide, contact ≤ 4.5 Å, contact ≤ 6.5 Å;
  - *Bond source*: Inter-chain (PDB), Intra-chain (PDB), Intra-chain (AlphaFold).
  For hover only, an unchecked group means: types = the four bonds and contacts ≤ 4.5 Å; sources = the PDB contacts
  (in the AlphaFold panel, its own contacts).
- **Lysines shown:** the highlighted lysines (structure number, chain, UniProt residue, NZ SASA; `AF ✓` if also
  highlighted in the AlphaFold panel). Clicking one pins it in both panels and zooms to the atoms within 10 Å; the
  highlighting of the others does not change.
- **Hover** a residue: yellow sticks, partners in their bond colour with a dashed line between the closest atoms and
  a label. **Click** pins (click again or *Clear pin* to release).

## AlphaFold panel (PDB structures)
- Shown on the left of the PDB view, same size, when exactly one chain is checked (otherwise collapsed, with the reason
  in the header bar). Both views have the same size so the linked camera gives the same magnification.
- The AlphaFold model of the chain's UniProt id (most common UniProt id of the chain) is superposed on that chain copy:
  least squares (Kabsch) on the Cα atoms matched by UniProt number and residue type, computed per bio chain in
  Python, applied in the page. The header shows RMSD and number of Cα (e.g. 4ah6 B1: 2.17 Å over 589 Cα; the page's
  transform reproduces the RMSD). At most 10 AlphaFold models per page; at least 10 matched Cα to fit.
- Cameras are linked both ways (`linkViewer`): rotating or zooming either view moves the other.
- The Lysines / bond type / bond source controls apply to it with the AlphaFold model's own contacts.
- Hover or pin in one view marks the residue at the same UniProt position in the other, each with its own partners;
  the info panel shows both. *Colour by pLDDT* (>90, 70–90, 50–70, <50) shows AlphaFold's confidence.

## Van der Waals and probe view (on pin)
- Protein atoms within 8 Å drawn as van der Waals spheres with FreeSASA's ProtOr radii by element (C 1.88, N 1.64,
  O 1.44, S 1.77 Å): carbons in the chain colour, the pinned residue's carbons yellow, N blue, O red, S yellow; the
  pinned lysine's NZ magenta and labelled. The pinned lysine's halo is not drawn.
- Green dots: probe-centre positions on the shell at r(NZ) + 1.4 Å (300 points; other residues: 80 per atom) where a
  1.4 Å probe touching NZ overlaps no other atom (Shrake–Rupley, computed in the page). The dots are centres, not
  probes; each stands for a full 1.4 Å probe.
- One translucent 1.4 Å probe at the most open position (cyan; red with "no room" if no position is open). Shapes are
  part of the scene, so they stay in place while rotating.
- Info panel: "k of N probe positions open ≈ X Å²". Only protein atoms count, as in the SASA computation (ligands,
  nucleic acids, waters excluded). Agreement with the stored FreeSASA NZ values: r = 0.999, mean difference
  0.6 Å² (4ah6, 64 lysines) and 0.8 Å² (3r45, 12 lysines).
- **Decision:** accessibility is the local definition (a probe fits next to the atom), as in FreeSASA; whether the
  probe can reach that position from bulk solvent is not checked, so enclosed cavities large enough for a probe count
  as accessible. Accepted as a good proxy.
